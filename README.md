# CS50x — Introduction to Computer Science

This repository contains the exercises, problem sets, labs, and projects developed throughout **Weeks 1–9 of CS50x — Introduction to Computer Science**, offered by Harvard University.

The course covers fundamental concepts of Computer Science and software development, starting with programming in C and progressing through algorithms, data structures, Python, SQL, and web development with Flask.

## Course Content

### Week 1 — C

Introduction to programming using the C language.

Main concepts:

- Variables and data types
- Conditionals
- Loops
- Functions
- Operators
- Input and output
- Compilation

---

### Week 2 — Arrays

Introduction to data manipulation using arrays and strings.

Main concepts:

- Arrays
- Strings
- Command-line arguments
- Character manipulation
- Basic cryptography
- Program organization in C

---

### Week 3 — Algorithms

Study of fundamental algorithms and techniques for solving computational problems efficiently.

Main concepts:

- Linear Search
- Binary Search
- Bubble Sort
- Selection Sort
- Merge Sort
- Recursion
- Algorithm complexity
- Big O notation

---

### Week 4 — Memory

Understanding how computer memory works and how programs interact with it.

Main concepts:

- Pointers
- Memory addresses
- Dynamic memory allocation
- `malloc`
- `free`
- Data representation
- File manipulation

---

### Week 5 — Data Structures

Introduction to fundamental data structures used in Computer Science.

Main concepts:

- Linked Lists
- Hash Tables
- Trees
- Stacks
- Queues
- Tries
- Dynamic data structures
- Memory management

---

### Week 6 — Python

Transition from C to Python while applying previously learned programming concepts in a higher-level language.

Main concepts:

- Python syntax
- Variables
- Conditionals
- Loops
- Functions
- Lists
- Dictionaries
- String manipulation
- File handling

Some problems previously implemented in C were recreated in Python, allowing comparison between different programming languages and levels of abstraction.

---

### Week 7 — SQL

Introduction to relational databases and Structured Query Language.

Main concepts:

- Relational databases
- `SELECT`
- `WHERE`
- `JOIN`
- `GROUP BY`
- `ORDER BY`
- Aggregate functions
- Table relationships
- Queries involving multiple tables

Exercises included database analysis and querying through problems such as **Songs**, **Movies**, and **Fiftyville**.

---

### Week 8 — HTML, CSS & JavaScript

Introduction to web development and interactive user interfaces.

Main technologies and concepts:

- HTML
- CSS
- JavaScript
- DOM
- Events
- Responsive design
- Web page structure

Projects developed during this week include interactive web pages and exercises such as **Trivia** and **Homepage**.

---

### Week 9 — Flask

Development of dynamic web applications using Python and Flask.

Main concepts:

- Flask
- Routes
- Templates
- Jinja
- Forms
- GET and POST methods
- Sessions
- Authentication
- SQL integration
- Dynamic web applications

During this week, **CS50 Finance** was developed, combining Flask, Python, SQL, HTML templates, authentication, and database operations in a complete web application.

---

The main skills developed include:

- Programming logic and problem-solving
- Algorithm design and complexity analysis
- Memory management
- Data structures
- Programming with C and Python
- Relational databases and SQL
- Front-end development
- Back-end development with Flask
- Integration between applications, databases, and user interfaces

## About CS50

**CS50x — Introduction to Computer Science** is Harvard University's introduction to Computer Science and the intellectual foundations of the field.

The course focuses on computational thinking, problem-solving, algorithms, data structures, programming languages, databases, and web development through practical assignments and projects.

This repository documents my progress throughout **Weeks 1–9**, leading up to the development of the **CS50 Final Project**.
